# 武學命名

狀態：**[已提出]**（2026-11-17）。Miku 認為第一版的名字「根本不武俠」，要求先整理傳統武俠與各作品的命名方式，再系統化本作的名稱。本文件記錄整理的結果、本作的命名規則，以及照規則得出的名字。

名字只是參考（Miku，2026-11-17）：之後會依世界觀做諧音等改動，所以這裡的規則管風格，不必逐字推敲。名字用在 [martial-arts.md](martial-arts.md) 與 [design.md](design.md) 4.8。

## 1. 第一版為什麼不武俠

- **招式名在描述機制：** 「鉤鎖拿人」「押解歸案」「剁骨斷筋」讀起來像說明書。武俠的招式名是意象或典故，看不出、也不必看出實際做什麼。
- **同一套路沒有母題：** 降龍十八掌的十八掌全部取自《易經》，打狗棒法的招式全都帶「狗」字，黯然銷魂掌全是表達情緒的成語。第一版每一招各自取名，湊在一起不像同一套武功。
- **全名少了結構：** 「追風刀」「斬岳刀」只有兩個形容字，沒有數字、出處，也沒有門派或流派的痕跡。

### 2.3 各家風格

- **金庸：** 重出處，一套武功一個典籍來源；全名常帶數字與陰陽。
- **古龍：** 招少而名險，一招就是一個意境；全名常帶「十三」「四十九」「八十一」這類數字。
- **溫瑞安：** 一個情緒字加上「一刀、一槍」。
- **傳統拳譜：** 動物、人物、自然加上一個動作，四字為主；同一套拳裡常混用多種來源。
- **網文與遊戲：** 偏霸氣字（斬、滅、天、魔）與抽象哲理詞（歸墟、和光同塵）。本作不走這條路。

## 3. 本作的命名規則

1. **全名＝出處或數字＋母題＋類別字。** 例：崩嶽十三刀、六扇門水火棍。畫面上可以只顯示簡稱（崩嶽刀）。
2. **一個套路一個母題，招式全部取自同一個來源。** 來源要是公有的古典：詩詞、成語、《易經》、《詩經》、史書典故、兵法、民間俗語。
3. **門派決定母題的來源與語氣。** 每個門派有自己的來源，例如漕幫用江河詩詞、六扇門用《三十六計》、九幽教用冥府。門派名冊見 [martial-arts.md](martial-arts.md)。

4. **招式四字；絕招可以破格。** 絕招可以是一句詩或俗語，字數不拘（古龍式）。
5. **數字取傳統的數：** 三、七、九、十三、十八、二十八、三十六、七十二、八十一。全名裡的數字是設定上的總招數；遊戲裡只做其中幾招，式數依套路而定（例如綠林十八刀只有兩式）。
6. **基本功用真實的傳統套路名**（六合刀、齊眉棍、金錢鏢、羅漢拳），讓起手就有江湖味。這些是公有的傳統武術名稱。
7. **心法用內功的寫法：** 某某功、某某訣，或直接用一句武術俗語（四兩撥千斤）。
8. **不撞名：** 名字不能和第 2 節整理到的任何一個武學或招式完全相同。上架前再查一次。
9. **極致的名字：** 屬性字加「・」加絕招名，例如「雷・五嶽同崩」。
